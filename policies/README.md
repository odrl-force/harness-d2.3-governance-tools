# Policies

Rules for the demo's data and services, in ODRL 2.2 with DPV 2.3 purposes. The catalogue
builds its offers from every file here.

P0 to P3 are Anna's rules for her meter readings. The authorisation server reads them to
decide each request.

P5 and P6 are Bob's: P5 for his own access, P6 to let anyone read his readings for
scientific research. The authorisation server reads them too.

P4 is EnerCo's offer for its AI forecast service. P4b bans credit checking on the service and its forecasts. P7 is EnerCo's access to its own pod. P8 lets Anna read the forecast of her household. The authorisation server reads P4b, P7 and P8.
